# Proyek Akhir

Bagian penutup: kamu membangun satu aplikasi yang memakai hampir semua yang sudah dipelajari, dari rancangan sampai pengujian dan operasi.

## Tujuan bagian

Setelah menyelesaikan bagian ini kamu bisa:

- [ ] Merancang key dan alur data Redis untuk sebuah aplikasi.
- [ ] Membangun API dengan cache, pembatasan laju, dan fitur realtime.
- [ ] Menerapkan persistence, keamanan, dan monitoring pada proyek itu.
